# Application de Fiche d'Inscription Scolaire en Excel VBA
Ce dépôt contient le code source VBA développé pour automatiser la gestion et 
l'enregistrement des fiches d'inscription scolaire directement via un formulaire 
Excel ergonomique.

# Fonctionnalités- Saisie centralisée via un *UserForm* interactif.- Validation automatique des champs obligatoires (Nom, Prénom, Classe, etc.).- Enregistrement structuré des données dans une feuille de calcul dédiée.- Gestion des erreurs et messages d'alerte pour l'utilisateur.

## 📂 Structure des fichiers- `Modules/Mod_Inscription.bas` : Logique d'enregistrement et contrôles de saisie.- `Forms/UserForm_Insc.frm` : Interface graphique du formulaire d'inscription.

## 💻 Utilisation
1. Ouvrir votre classeur Excel activé pour les macros (`.xlsm`)
2. 2. Appuyer sur `ALT + F11` pour ouvrir l'éditeur VBA.
3. Importer les fichiers `.bas` dans vos modules et copier le code du formulaire
